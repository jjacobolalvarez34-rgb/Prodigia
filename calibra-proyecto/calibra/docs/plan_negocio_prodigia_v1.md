# PRODIGIA
## Plan de negocio, monetización, marketing y estrategia de crecimiento
### Versión 1 — septiembre de 2026

---

# 1. Resumen ejecutivo

Prodigia será una plataforma de práctica y aprendizaje adaptativo presentada como una experiencia de juego.

El concepto central no es “hacer tareas”, sino **entrar a un mundo, mejorar una habilidad, competir, conseguir progreso y volver mañana**.

La propuesta actual tiene:

- Mundos temáticos.
- Práctica adaptativa.
- Caminos de aprendizaje.
- Dificultad calibrada en tiempo real.
- Duelos 1v1 con ELO.
- Rachas y retos diarios.
- Logros y medallas.
- Economía de puntos.
- Tienda cosmética.
- Amigos.
- Grupos para profesores.
- Feed social controlado sin chat libre.
- Onboarding progresivo.

La arquitectura actual separa correctamente varias economías de progreso: Puntos, Experiencia, nivel del mundo y ELO. Esto es importante porque permite crear monetización sin convertir el sistema competitivo en “pay to win”.

El negocio recomendado es un modelo híbrido:

**Freemium + suscripción Pro + publicidad limitada + economía cosmética + B2B educativo.**

No recomiendo depender exclusivamente de publicidad.

La publicidad debe servir principalmente para monetizar al usuario gratuito; el dinero verdaderamente importante a largo plazo debería venir de los usuarios que encuentran suficiente valor como para pagar Pro y, posteriormente, de instituciones educativas.

---

# 2. Qué estamos vendiendo realmente

No estamos vendiendo preguntas de matemáticas.

Tampoco estamos vendiendo “una app educativa”.

Estamos vendiendo:

> **Una forma divertida de convertir el aprendizaje en progreso visible.**

Ese posicionamiento es fundamental.

Un usuario debería sentir:

“Voy a entrar cinco minutos.”

Y terminar pensando:

“Una partida más.”

El valor económico de Prodigia dependerá mucho menos de cuántos ejercicios tenga y mucho más de cuánto consiga convertirse en un hábito.

---

# 3. Problema que queremos solucionar

Existen tres problemas principales.

## Problema A — Aprender suele sentirse como obligación

Muchas plataformas educativas presentan el aprendizaje como una actividad académica tradicional.

Prodigia debe intentar transformar esa percepción.

## Problema B — El contenido frecuentemente no se adapta suficientemente

Dos personas pueden estar estudiando exactamente el mismo tema y tener niveles completamente diferentes.

Prodigia ya tiene una ventaja conceptual importante aquí:

la dificultad puede subir o bajar en tiempo real según desempeño y velocidad.

## Problema C — Falta una razón para volver mañana

La mayoría de aplicaciones educativas tienen contenido.

El verdadero desafío comercial es crear:

**hábito + progreso + identidad + competencia + recompensa.**

Por eso existen rachas, ELO, niveles, logros, retos diarios, amigos y cosméticos.

# 4. Público objetivo

No debemos intentar venderle Prodigia a “todo el mundo” inicialmente.

Eso normalmente destruye el marketing.

## Público primario

Mi primera hipótesis de mercado sería:

**jóvenes y estudiantes que quieren mejorar habilidades académicas pero toleran mal las experiencias educativas tradicionales.**

Particularmente:

- matemáticas;
- lógica;
- cultura/geografía;
- práctica corta;
- competencia;
- progreso visual.

## Público secundario

Padres que quieren una herramienta de práctica para sus hijos.

## Público terciario

Profesores e instituciones educativas.

Este tercer grupo es particularmente importante porque el sistema de Grupos ya está contemplado en el producto: el profesor puede crear grupos y consultar estadísticas agregadas e individuales.

Esto puede convertirse posteriormente en una segunda línea de negocio.

# 5. Modelo de negocio recomendado

La estructura ideal sería:

### FREE

Entrada completamente gratuita.

Incluye suficiente contenido para que el usuario pueda enamorarse del producto.

Monetización mediante:

- publicidad;
- compras cosméticas opcionales.

### PRO

Suscripción mensual/anual.

El objetivo de Pro no debe ser:

“pagar para poder aprender”.

Debe ser:

“pagar para obtener la experiencia completa”.

### COSMÉTICOS

Skins, estandartes, efectos, personalización, marcos, insignias y elementos visuales.

Nunca vender ventajas competitivas.

Esto coincide con la arquitectura actual del producto, donde los cosméticos no deben dar ventaja en duelos y el ELO debe mantenerse limpio.

### B2B EDUCATIVO

Más adelante:

- profesores;
- academias;
- colegios;
- instituciones educativas;
- programas de refuerzo.

Esto puede convertirse eventualmente en una fuente de ingresos mucho más grande que el consumidor individual.

# 8. Lo que NO debemos vender

Hay varias cosas que considero peligrosas para la identidad del producto.

No vender:

- multiplicadores de ELO;
- ventaja en duelos;
- respuestas;
- puntos que sustituyan habilidad;
- victoria automática;
- dificultad artificialmente reducida;
- ventajas competitivas.

Eso destruiría una de las propiedades más interesantes de Prodigia.

El usuario debe poder presumir:

> “Llegué aquí porque soy bueno”.

No:

> “Llegué aquí porque pagué.”

---

# 9. Publicidad

Aquí hay que ser extremadamente cuidadosos.

La publicidad puede generar dinero, pero también puede destruir la experiencia.

## Banner

Uso muy limitado.

Nunca encima de botones importantes, preguntas o elementos interactivos.

## Interstitial

No después de cada pregunta.

No después de cada respuesta.

No durante un duelo.

No en medio de una sesión.

Sí podría aparecer:

**al finalizar una sesión**, después de ciertos recorridos o en una transición natural.

## Rewarded Ads

Aquí tenemos una oportunidad mucho más interesante.

El usuario decide voluntariamente ver un anuncio a cambio de algo.

Por ejemplo:

> “Ver anuncio → +50 Puntos”

o:

> “Ver anuncio → una recompensa cosmética temporal”

o:

> “Ver anuncio → recuperar una recompensa del día”

La regla es:

**nunca obligar al usuario a ver el anuncio para continuar.**

---

# 10. El objetivo real de la publicidad

No debería ser:

> “Maximicemos impresiones.”

Debería ser:

> “Moneticemos al usuario gratuito sin aumentar demasiado la probabilidad de que abandone.”

Es una diferencia enorme.

Un usuario gratuito que genera US$0.20 pero permanece seis meses puede ser mucho más valioso que uno que genera US$0.80 y abandona después de tres días.

---

# 11. Cómo evitar que Prodigia parezca una app llena de anuncios

Regla propuesta:

### Pantallas críticas de aprendizaje

**Cero anuncios invasivos.**

### Duelos

**Cero anuncios durante la partida.**

### Resultado de una actividad

Posibilidad de anuncio en un momento natural.

### Menús

Publicidad mínima.

### Rewarded

Principal mecanismo publicitario interactivo.

### Pro

Cero anuncios.

De hecho, “sin anuncios” debe ser una de las razones más fáciles de entender para comprar Pro.

Aquí tenemos un elemento extremadamente potente.

**Puntos = moneda**

y

**Experiencia = ranking semanal.**

Esta separación es excelente y debemos conservarla.

Los Puntos pueden alimentar una economía virtual.

El usuario obtiene puntos mediante:

- practicar;
- completar lecciones;
- rachas;
- retos;
- logros;
- duelos;
- actividades especiales;
- anuncios recompensados.

Y los gasta en:

- estandartes;
- marcos;
- efectos;
- avatares;
- cosméticos;
- animaciones;
- personalizaciones.

Esto introduce una segunda capa de monetización.

# 13. Economía cosmética

Aquí quiero ser especialmente agresivo en diseño pero prudente en negocio.

No necesitamos vender “poder”.

Necesitamos vender:

**estatus + identidad + rareza.**

Ejemplo:

Bronce

→ Plata

→ Oro

→ Platino

→ Diamante

→ Prodigio

Los seis estandartes de rango encajan perfectamente aquí como sistema visual de rango.

Los objetos visuales pueden tener:

- rareza;
- temporadas;
- colecciones;
- exclusividad;
- animaciones;
- variantes.

Ejemplo:

“Estandarte Prodigio — Temporada 1”

No mejora el jugador.

Pero sí dice:

**“Yo estuve aquí.”**

Eso es monetizable.

# 26. La métrica más importante del modelo económico

**LTV — Lifetime Value**

Necesitamos saber cuánto dinero genera un usuario promedio durante toda su vida dentro de Prodigia.

Y después:

**CAC — Customer Acquisition Cost**

cuánto cuesta conseguirlo.

La regla fundamental:

> LTV debe superar CAC de forma saludable.

Como objetivo inicial de negocio, buscaría eventualmente una relación aproximada de:

**LTV:CAC ≥ 3:1**

aunque durante la fase experimental podemos estar por debajo.

# 27. Ejemplo económico inicial

Supongamos hipotéticamente:

10.000 usuarios activos mensuales.

Supongamos:

5% convierten a Pro.

Eso significa:

500 usuarios Pro.

Con US$4.99:

500 × 4.99 =

**US$2,495/mes brutos.**

Además:

9.500 usuarios gratuitos generan publicidad y eventualmente compras cosméticas.

Esto demuestra por qué no debemos pensar:

“la publicidad será nuestro negocio”.

Puede ser un complemento.

La suscripción tiene mayor potencial de predictibilidad.

---

# 28. Escenario de 100.000 MAU

Supongamos:

100.000 usuarios activos mensuales.

5% Pro.

= 5.000 usuarios de pago.

5.000 × US$4.99

= **US$24.950/mes brutos de suscripciones mensuales equivalentes**

antes de comisiones de las tiendas, impuestos, promociones, reembolsos y demás costos.

Además la publicidad puede comenzar a tener relevancia.

Pero el objetivo sigue siendo convertir una pequeña parte de esos usuarios en usuarios de alto valor.

---

# 29. Comisiones de las tiendas

Tenemos que modelar esto desde el principio.

Apple ofrece el Small Business Program con una comisión reducida del 15% para desarrolladores elegibles, bajo las condiciones correspondientes.

Google Play también contempla una comisión del 15% para el primer US$1 millón anual para desarrolladores que cumplen las condiciones del programa de tarifa correspondiente, y las suscripciones tienen una tarifa del 15% en la estructura descrita por Google.

Por eso nuestros modelos financieros nunca deben tratar:

**US$4.99 vendidos = US$4.99 para Prodigia.**

No es así.

# 30. Costos tecnológicos actuales

Tu stack es:

Next.js + TypeScript + Tailwind

Supabase

Vercel

Framer Motion / React Bits.

Esto es bueno porque permite comenzar relativamente pequeño.

Por tanto, técnicamente Prodigia no necesita comenzar quemando miles de dólares mensuales.

# 33. El verdadero gasto no será el servidor

Esto es importante.

El mayor gasto a largo plazo probablemente será:

**adquisición de usuarios + desarrollo + contenido + operación.**

No debemos obsesionarnos con ahorrar US$20 de infraestructura si después gastamos US$2.000 consiguiendo usuarios que abandonan.

# 34. Punto de equilibrio

Supongamos que eventualmente tenemos:

US$5.000 mensuales de costos operativos totales.

Y que cada suscriptor Pro deja aproximadamente US$4 netos después de comisiones y ajustes.

Necesitaríamos:

5.000 / 4

≈ **1.250 suscriptores activos**

para cubrir esos costos mediante suscripciones.

Pero esta cifra cambia completamente si tenemos:

- ingresos publicitarios;
- cosméticos;
- anualidades;
- B2B.

Por eso construiremos un modelo financiero real posteriormente.

# 35. Suscripción anual

Quiero que empujemos mucho la suscripción anual.

¿Por qué?

Porque mejora el flujo de caja.

US$39.99 cobrado hoy es diferente de recibir US$4.99 mensualmente durante ocho meses.

Además reduce churn mensual.

El pricing deberá probarse.

Podríamos eventualmente experimentar con:

US$4.99 mensual

US$39.99 anual

y eventualmente una variante promocional.

---

# 36. No regalar demasiado Pro

Pero tampoco bloquear demasiado.

La pregunta que vamos a hacerle constantemente al producto será:

> “¿Esto hace que el usuario quiera pagar o simplemente hace que odie la app?”

Un paywall malo dice:

“Completa 3 ejercicios. Paga para continuar.”

Un paywall bueno dice:

“Llevas 17 días practicando. Mira todo lo que has mejorado. Con Pro puedes desbloquear análisis avanzados y continuar sin anuncios.”

El segundo vende el valor.

# 45. Ventaja competitiva

No sería:

“Tenemos más preguntas”.

Eso es copiable.

Las ventajas potenciales son:

**adaptación + juego + competencia + mundos + identidad + datos de aprendizaje.**

La combinación es más difícil de replicar que una colección de ejercicios.

---

# 46. Moat

A largo plazo, el activo más valioso puede convertirse en:

**datos de aprendizaje anonimizados/agregados + modelos de dificultad + comportamiento de usuarios + contenido + red social + sistema competitivo.**

Cada interacción puede ayudarnos a entender:

- qué tan difícil es una pregunta;
- cuánto tarda;
- qué errores son comunes;
- cuándo abandona;
- qué tipo de recompensa funciona;
- qué tipo de contenido genera retención.

Eso puede mejorar el sistema adaptativo.

# 47. Contenido infinito

En Enigmia ya existe un componente especialmente interesante:

generación procedural para algunas categorías, produciendo contenido potencialmente infinito.

Esto puede reducir una parte importante del costo de creación manual de contenido.

Pero habrá que vigilar:

- calidad;
- repetición;
- dificultad;
- errores;
- consistencia pedagógica.

# 48. IA

No convertiría Prodigia inmediatamente en:

“una app de IA”.

- clasificar dificultad;
- analizar errores;
- crear variaciones;
- asistir a creación de contenido.

Pero al usuario le vendemos:

**mejor aprendizaje**.

No:

**tenemos IA porque sí.**

# 50. Privacidad

Yo conservaría esa decisión.
