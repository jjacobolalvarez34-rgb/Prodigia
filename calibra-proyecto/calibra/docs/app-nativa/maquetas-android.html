Prodigia para Android — maquetas de referencia

Dirección "Noche de Prodigia": oscuro por defecto, el color de cada mundo es la luz. Son referencias de distribución y tono visual para docs/app-nativa/02-SISTEMA-VISUAL.md y 03-PANTALLAS-Y-NAVEGACION.md; los datos son de ejemplo. Los botones grandes y las teclas se pueden presionar para sentir el volumen.

Color por mundo: base (existe) + neón (propuesta)

El neón es el acento dentro de cada mundo sobre fondo oscuro. Validar contraste AA antes de fijar los valores.
